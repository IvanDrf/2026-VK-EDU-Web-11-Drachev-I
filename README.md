# Что сделано?

Сверстал 7 статических страниц.

Bootstrap подключается не через CDN.

Добавил `favicon.ico`

Адаптивная верстка под мобильные устройства.

Страницы
- **index.html**

    Основная страница с вопросами, поиском вопросов по теме, тегами по темам вопросов, например, python/Django.

- **signup.html**

    Страница регистрации пользователя, с полями: аватарка, имя пользователя, почта, пароль.

- **login.html**

    Страница входа в аккаунт, чтобы войти в аакаунт нужно ввести почту или имя пользователя и пароль.

- **settings.html**

    Страница настроек данных о пользователе, можно поменять аватарку, имя пользователя, почту.

- **ask.html**

    Страница для задавания вопроса, содержит название нового вопроса, его текст и теги.

- **question.html**

    Страница с одним вопросом. Открывается при нажатии на вопрос с главной страницы (**index.html**). Открывается полное название и описание вопроса, а также ответы к нему.

- **tag.html**

    Страница с поиском вопросов по тегу, сейчас при нажатии на любой тег открывается страница с вопросами, содержащими тег `python`.


## Как запустить

1) Перейти в директорию `public/`

2) Выбрать файл `index.html`

3) Открыть файл `index.html` с помощью Live Server(VS Code)

4) Перейти на `http://localhost:5500` в браузере
